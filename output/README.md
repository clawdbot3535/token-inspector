# Figma Tokens → Nuxt UI

Generated by `build-tokens.mjs` from `components/*.tokens.json` (Figma W3C DTCG export).

## Was du bekommst

| Datei | Inhalt | Ziel |
|---|---|---|
| `tokens.css` | CSS Custom Properties in 3 Schichten: Primitives → Semantic (light/dark) → Components | `assets/css/tokens.css` |
| `tokens.ts` | Typsicheres `tokens`-Objekt mit `as const` + `cssVar(name)` Helper | `app/utils/` oder `shared/` |
| `nuxt-ui.app.config.ts` | Vorlage für Nuxt UI v3 `app.config.ts` mit Color-Aliasen | merge mit deinem `app.config.ts` |

## Drop-in in dein bestehendes Nuxt-Projekt

### 1. CSS einbinden

Kopiere `tokens.css` nach `assets/css/tokens.css` und registriere in `nuxt.config.ts`:

```ts
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  css: ['~/assets/css/tokens.css'],
});
```

Die Datei definiert CSS-Variablen in drei Layers:

- `:root` → alle Primitives (`--color-neutral-500`, `--spacing-4`, `--font-size-text-base` …)
- `:root, html.light` → Semantic (`--color-bg-base`, `--color-text-primary` …) — light by default
- `html.dark` → Semantic dark overrides (Nuxt UI's `useColorMode` setzt `html.dark` automatisch)
- `:root` → Component tokens (`--button-padding-y`, `--card-bg` …) — verweisen auf semantic/primitive vars

### 2. Typsicherer Zugriff in Vue-Komponenten

```vue
<script setup lang="ts">
import { tokens, cssVar } from '~/utils/tokens';

const buttonRadius = tokens['button-radius']; // "var(--rounded-sm)" → resolved at runtime
const bg = cssVar('color-bg-elevated');       // "var(--color-bg-elevated)"
</script>

<template>
  <div :style="{ background: bg, borderRadius: buttonRadius }">…</div>
</template>
```

### 3. Nuxt UI Color-Aliase

Merge `nuxt-ui.app.config.ts` mit deinem `app.config.ts`. Die Color-Tokens haben Skalen `accent`, `neutral`, `red`, `amber`, `green`, `blue` (50–950). Standard-Mapping:

```ts
ui: {
  colors: {
    primary: 'blue',
    neutral: 'zinc',
  },
}
```

Wenn `accent` deine Marken-Primärfarbe ist, ändere zu `primary: 'accent'` — dafür müssen die Tailwind-Tokens `accent-50` … `accent-950` registriert sein (siehe Tailwind v4 Setup).

### 4. Tailwind v4 Theme (optional, empfohlen mit Nuxt UI)

In deinem `assets/css/main.css` (das von Nuxt UI auto-importierte Tailwind-Stylesheet):

```css
@import "tailwindcss";
@import "@nuxt/ui";
@import "./tokens.css";

@theme {
  --color-accent-50:  var(--color-accent-50);
  --color-accent-500: var(--color-accent-500);
  --color-accent-600: var(--color-accent-600);
  /* … etc. — Tailwind v4 erlaubt vars als Theme-Werte */

  --spacing: 4px; /* falls deine Skala in 4px-Schritten arbeitet */
  --radius-sm: var(--rounded-sm);
  --radius-md: var(--rounded-md);
  --radius-lg: var(--rounded-lg);
}
```

Damit funktionieren Tailwind-Klassen wie `bg-accent-500`, `rounded-md`, `p-4` direkt mit deinen Figma-Werten.

## Token-Struktur (Übersicht)

- **Primitives** (145 Tokens, source-of-truth)
  - `color`: white, black, transparent, neutral 50–950, accent 50–900, red/amber/green 50–900 + alpha
  - `spacing`: 0, 1, 1-5, 2, 2-5, 3, 4, 5, 6, 8, 10, 12, 16, 20, 24
  - `rounded`: none, xs, sm, md, lg, xl, 2xl, 3xl, full
  - `border`: 0, 1, 2, 4, 8 (px)
  - `shadow`: sm, md, lg, xl, focus (CSS box-shadow values)
  - `font-family`: display, body, code
  - `font-size`: text-2xs … text-7xl
  - `font-weight`: thin … black
  - `line-height`, `letter-spacing`

- **Semantic** (51 Light + 51 Dark, gleiche Pfade)
  - `color/bg/{base, elevated, subtle, muted, emphasis}`
  - `color/text/{primary, secondary, muted, toned, disabled, inverted, accent, on-accent}`
  - `color/border/{default, …}`
  - … weitere semantische Rollen

- **Component overrides** (318 Tokens) — pro Komponente: `padding-x`, `padding-y`, `radius`, `gap`, `font-size`, `bg`, `border`, etc.
  - `button`, `input`, `card`, `badge`, `dropdown`, `modal`, `nav`, `typography`, `table`, `progress`, `kbd`, `checkbox`, `radio`, `switch`, `chip`, `textarea`

## Re-build

Wenn du in Figma neue Token-Exporte machst, ersetze die Dateien in `components/` und führe aus:

```bash
node build-tokens.mjs
```

## Bekannte Quirks

- Figma exportiert `font-weigth` und `line-heigth` (Typo) — werden im Output zu `font-weight`/`line-height` normalisiert.
- `shadow.sm` und `shadow.md` waren im Quell-Export am `)` abgeschnitten — wird automatisch balanciert.
- `--color-*-alpha-500-10` etc. werden als `rgba()` ausgegeben (nicht als hex+alpha).
